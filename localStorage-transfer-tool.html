🔄 HPM LocalStorage Transfer Tool

Transfer your HPM data between computers easily

📤Export Data (From Old Computer)

  1. Open your HPM application on the old computer
  2. Open Developer Console (F12 or Right-click → Inspect)
  3. Copy the code below and paste it into the Console
  4. Press Enter - your data will download as a file
  5. Transfer that file to your new computer
// Export all localStorage data
const data = {};
for (let i = 0; i < localStorage.length; i++) {
    const key = localStorage.key(i);
    data[key] = localStorage.getItem(key);
}

// Create download
const blob = new Blob([JSON.stringify(data, null, 2)], {type: 'application/json'});
const url = URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url;
a.download = 'hpm-data-export.json';
a.click();
console.log('✅ Data exported! Check your downloads folder.');

📥Import Data (To New Computer)

⚠️ Warning: This will overwrite existing data on this computer. Make sure you're on the right machine!
  1. Open this page on your new computer
  2. Click "Choose File" below and select your data.csv or exported JSON file
  3. Click "Import Data to Browser"
  4. Open your HPM application - your data will be there!

⌨️Alternative: Manual Import via Console

If you prefer to paste data directly into the console:

  1. Open HPM on your new computer
  2. Open Developer Console (F12)
  3. Paste your data in the textarea below
  4. Click "Generate Import Script"
  5. Copy and paste the generated script into the console
